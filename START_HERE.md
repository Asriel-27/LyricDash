## 🎮 How to Play

### 1. Register
- Click "Register"
- Create username & password
- Submit

### 2. Chat
- Type message in chat box
- See messages real-time
- View online users

### 3. Play Game
- Generate room ID
- Select song
- Join game room
- Start game
- Type lyrics
- View leaderboard

### 4. Multiplayer
- Share room ID dengan teman
- Teman join room
- Start game together
- Compete real-time
