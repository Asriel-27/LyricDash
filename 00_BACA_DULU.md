## 🎯 APA INI?

**LyricDash** adalah aplikasi web multiplayer yang menggabungkan:
- 🎮 **Typing Game** - Berlomba mengetik lirik lagu
- 💬 **Chat Room** - Chatting real-time dengan pemain lain
- 🎵 **Audio** - Musik dimainkan saat bermain game
- 📊 **Leaderboard** - Ranking berdasarkan WPM dan akurasi

Semua **sudah jadi**, semua **sudah teruji**, dan semua **siap pakai**!

## ⚡ MULAI SEKARANG (3 LANGKAH)

### 1️⃣ Setup (pilih satu):

**Windows:**
```bash
setup.bat
```

**macOS/Linux:**
```bash
bash setup.sh
```

**Manual:**
```bash
cd backend
npm install
```

### 2️⃣ Jalankan:
```bash
cd backend
npm start
```

### 3️⃣ Buka Browser:
```
http://localhost:3000
```

## 🎮 Cara Main (Sangat Mudah!)

1. **Register** → Buat akun baru
2. **Login** → Masuk dengan username & password
3. **Chat** (Opsional) → Chatting dengan users lain
4. **Game** → 
   - Generate room ID
   - Invite teman (share room ID)
   - Select lagu
   - Start game
   - Mengetik lirik sambil dengarkan musik
   - Lihat leaderboard
5. **Done!** → Siap main lagi
